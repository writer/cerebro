# Agent Interaction Examples

This directory contains example agent conversations and interaction patterns for Cerebro security agents.

## Files

### Conversation Transcripts
- `critical_iam_investigation.md` - Agent investigating overprivileged service accounts
- `incident_response_session.md` - Data exfiltration incident response
- `compliance_audit_session.md` - Multi-framework compliance review
- `attack_path_analysis.md` - Threat modeling and attack path discovery

### Interaction Patterns
- `approval_workflows.md` - Examples of agent approval requests and workflows
- `tool_usage_patterns.md` - Common tool usage patterns and best practices
- `analytics_reports.md` - Sample analytics and reporting interactions

### Agent Prompts
- `security_investigation_prompts.txt` - Common investigation prompts
- `compliance_prompts.txt` - Compliance and audit prompts  
- `incident_response_prompts.txt` - Incident response prompts

## Usage

These examples demonstrate:
- How agents interact with users during investigations
- Proper tool usage patterns
- Approval request formatting
- Report generation workflows
- Investigation methodologies

Use these as templates for:
- Training new security analysts
- Testing agent capabilities
- Developing new agent features
- Documentation and demos

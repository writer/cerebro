# Cerebro Documentation

This directory contains developer-facing documentation for Cerebro. Files are organized by topic (getting started, developer-guide, integrations, agents, architecture). Most documents are reference material aimed at engineers maintaining or extending the system.

---

## 📚 Documentation Index

## Directory Map

| Path | Notes |
|------|-------|
| `getting-started/` | Local setup and first-use instructions |
| `developer-guide/` | Development workflow, schema reference, deployment runbooks |
| `user-guide/` | REST/CLI usage, CEL rules, troubleshooting |
| `agents/` | Agent runtime internals, tool catalog, integration notes |
| `integrations/` | Provider and notification integration docs |
| `architecture/` | Deeper design documentation |
| `archive/` | Historical documents and session notes (review before deletion) |

## Maintenance Notes

- Prefer concise, technical documentation—avoid marketing copy.
- When removing historical documents, move them under `archive/` if they may still be useful.
- Update this index when new top-level sections are added or removed.
